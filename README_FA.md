# سرور لوکال Animal Rush

بک‌اند کامل + سرور اختصاصی FreeRide برای اجرای لوکال بازی (جایگزین api.sizakgames.ir).
نیازمندی: Node.js (نصب است).

## اجرا
دابل‌کلیک روی:  **START_LOCAL.bat**

۳ چیز بالا می‌آید:
1. بک‌اند لوکال روی پورت 8899 (لاگ: backend.log)
2. سرور اختصاصی FreeRide (پورت 9000، لاگ: srv_freeride.log)
3. خود بازی وصل به بک‌اند لوکال

سپس داخل بازی:  PLAY -> FreeRide -> سرور "FreeRide Server 1" -> Join

برای حالت مسابقه (Race): بعد از START_LOCAL، فایل **RUN_RACE_SERVER.bat** را هم بزن
(سرور Race پورت 9001). سپس در بازی حالت Race -> Join.

بازیکن دوم روی همین کامپیوتر: **RUN_CLIENT_ONLY.bat**
بستن همه: **STOP_ALL.bat**

## چه چیزی درست شده (این نسخه)
- آرگومان‌های بازی حالا بدون خط تیره‌اند (بازی خودش key=value می‌خواهد): backend=http://127.0.0.1:8899
- همهٔ 159 شخصیت برای هر حساب از پیش باز است -> انتخاب شخصیت کار می‌کند.
- سرور FreeRide حالا با مُد FreeRide ثبت‌نام می‌شود و در لیست سرورها دیده می‌شود.
- بک‌اند: register/sync/save/shop/daily/leaderboard/clan/police/jobs همه تست‌شده (22/22).

## نکته‌ها
- سکهٔ اولیه: 100,000 (state.json؛ پاکش کنی ریست می‌شود).
- چت عمومی به Nakama اصلی وصل می‌شود؛ نبودش فقط چت را خالی می‌کند.

  واقعی سایر بازیکن‌ها) به‌صورت حداقلی پاسخ می‌دهند. اگر بخشی خطا داد، اسمش را بگو.
